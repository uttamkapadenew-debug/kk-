# StaffHub Permanent UI Requirements

- The dashboard must always show the prominent `Staff Attendance Calendar` button above the summary cards.
- Keep the button ID `dashboardCalendarBtn` and its staff/month picker behavior intact.
- Keep the per-employee `Calendar` actions available.
- Do not remove, rename, relocate, hide, replace, or redesign this dashboard Calendar section during unrelated work.
- Only change this protected section when the user explicitly asks to revoke or modify this exact requirement.
